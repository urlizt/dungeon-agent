Questions

The things people ask first.

Your cloud machine

What exactly is a Cloud machine?

A dedicated Linux dev machine we run for you — 8 CPU cores, 8 GB RAM and roughly 100 GB of storage — with the agents preinstalled. It is in your device list; opening it the first time is what creates it and links it to your account. Usually that takes seconds, because machines are kept ready; when one has to be built from scratch it can take up to 25 minutes, and the page says so while it works.

It is in preview: included with Remote Max while we learn how people use it. Later it graduates to a plan of its own, from $5/mo.

Does what I install stay?

Yes. It is a persistent machine, not a per-session container: cloned repos, installed packages, dotfiles and agent sign-ins are all still there next time. Between sessions it goes to sleep and picks up where it left off.

Reset my Cloud in the row's menu trades it for a brand-new one, and asks first. It is not the only way the disk goes: there are no automatic backups, and a machine can be rebuilt or reclaimed — when a preview ends, a subscription lapses, or maintenance needs it. Push anything you care about to your own repositories.

Which agents can it run?

All four come preinstalled and all four connect right from the browser. Muse Code guides you through Meta's sign-in when you press Connect. Grok and Codex use a device code — Codex needs one toggle enabled in your OpenAI account first, and the connect flow walks you through it. Claude Code works differently: you open a link, approve there, and paste the code it gives you back into the page.

Connectors (MCP apps) work there too — you sign one in from the browser, and the sign-in finishes on the machine without anything to copy across.

Using it

Is it the same extension as Grok Build for VS Code?

Yes. Same extension, same ID (PawelHuryn.grok-vscode-phuryn), same settings and conversations. It was listed as “Grok Build for VS Code (Community)” until September 2026 and as “GUI for Grok Build & Muse Code” until October 2026, and became AFK Pilot in version 4.15.0 on October 16, 2026. If your editor updates extensions automatically, which is its default, the new name arrives on its own.

Which agents does it run?

Grok Build (SpaceXAI, formerly xAI), Muse Code (Meta), Codex (OpenAI) and Claude Code (Anthropic), plus Google's Antigravity as an experimental fifth on your own computer. Each is the vendor's own agent, signed in with your own account. You see whatever models each one offers you — for example Grok 4.7, Muse Wonder or Opus 5.5, and Gemini 4 Argon when Antigravity is connected with a Gemini API key. Cloud machines run the first four. Each conversation keeps the agent it started with.

Does it work with Antigravity?

As an agent, yes, experimentally. Turn on Settings → Advanced → Experimental: Antigravity, then connect it in Settings → Providers with your Google account or a Gemini API key; a key also offers Gemini 4 Argon. It is off by default and runs on your own computer only: not on Cloud machines, signed in at the computer rather than from your phone, and with no Plan mode or connectors yet. AFK Pilot starts its own Antigravity conversations, through Google's ACP server, next to your other agents.

What can I do from the browser?

Nearly everything the sidebar does. The browser client is the host's chat UI — same layout, same controls — pointed at your machine instead of a local panel. What stays behind is whatever needs the host's local UI, whether that host is VS Code or Grok Build Desktop.

From any browser

  • Approve file writes, commands and plans
  • Dictate with your voice where the host has voice set up, and have replies read aloud
  • Switch model, mode and effort — and the repository each tab works in
  • See every project and its conversations; resume, rename, delete or archive them
  • Give a project its own colour and icon, and see it wherever that project is named
  • Open, edit and save project files, syntax-highlighted
  • Attach workspace files with @, add photos and documents
  • Connect Grok, Codex, Claude Code or Muse Code to a machine
  • Connect an app to an agent, and update an agent's CLI in place
  • Follow an agent's subagents and workflows as they run, and copy what each one returns
  • Update a Cloud machine to the latest release — it waits until the agent is idle
  • Edit the config file each agent's CLI reads
  • Add a project — name a new one, or clone it from a URL
  • Rewind the conversation, or edit a message you already sent
  • Sign in to GitHub, and clone a private repository onto a Cloud machine
  • Pick up the conversation open in VS Code or Desktop — both stay live
  • Export the conversation as Markdown

Only at the desk

  • Importing a folder that is already on the machine — that opens a file picker there
  • Signing agents out of a local machine — a Cloud machine can be signed out remotely

Does it work with Codex and Claude Code?

Yes — both, alongside Grok and Muse Code. Models from every connected agent appear in one picker, and each conversation keeps the agent it started with, so you can run them side by side: five on your own machine, counting the experimental Antigravity, and four on a Cloud machine.

These are the original harnesses, not a re-implementation. We run the vendors' own command-line agents — the Grok Build CLI, OpenAI's Codex CLI, Anthropic's Claude Code CLI and Meta's Muse Code CLI — on your machine. Grok, Codex and Claude Code connect over the open Agent Client Protocol; Muse Code uses Meta's own protocol through an adapter. Each agent keeps its own models, tools and updates; what this app adds is one interface over all of them, and a browser you can reach it from. Available controls depend on the agent. You sign in with your own accounts and your usage counts against your own subscriptions.

On a Cloud machine: all four connect right from the browser.

On your own machine: Grok, Codex, Claude Code and Muse Code all connect in Settings → Providers (if the Codex CLI isn't installed, the app offers to install it) — and once connected, the browser drives any of the four. Google's Antigravity joins them there as an experimental fifth agent (Settings → Advanced), on your own machine only, not on Cloud machines.

Do I need to leave my computer on?

Not if you use a Cloud machine — that one runs in our cloud and sleeps on its own, so your laptop can stay shut.

For an agent on your own machine, yes. It runs there, in either the AFK Pilot extension or Grok Build Desktop (Community), with your own model access — AFK Pilot is only the wire between it and your browser. Leave the host running and the workspace linked.

In VS Code, you do not have to leave the AFK Pilot panel open, but you do have to open it once after you start VS Code: that is what dials the connection. In Desktop, open the app and link it from its AFK Pilot controls. After that, the local panel can be out of the way while the link stays up — and on Windows and Linux, closing the Desktop window leaves the app running in the tray, so the link survives that too.

While a device is linked, the extension holds your operating system's own wake lock so the machine will not idle-sleep and drop the connection while you are away. Your screen still goes dark, and grok.remote.keepAwake turns the whole thing off. If the machine does go down, the device simply shows as offline and reconnects by itself when it comes back.

Is my phone one of my linked devices?

No. A linked device is a machine running a host — an IDE such as VS Code, or Grok Build Desktop — and that is what the Free plan's one-device limit counts. Running both hosts on the same computer still counts as one device. Open the browser client on as many phones, tablets and laptops as you like; they all reach the same workspace, and two of them can watch the same run at once.

Your data

Do you store my prompts or my code?

No. Prompts, replies, file contents and images pass through the relay in memory and are dropped. There is no chat history on our servers because there is no chat log on our servers — your sessions live on the machine running the agent, the same as they did before. On a Cloud machine that is the machine we host for you: the conversations and files are on its disk, and still not in our database.

What we do keep is the minimum to run an account: your sign-in identity, a device name and key identifier, and, on the Free plan, a single number — how many messages you have sent this week. The privacy policy lists all of it.

Is it end-to-end encrypted?

Both hops are encrypted: browser to relay, and relay to your machine, each over TLS. Nothing crosses the network in the clear.

It is still not end-to-end, and we would rather say so than imply otherwise: the relay terminates both hops to route between them, so a message is briefly in plaintext in its memory as it passes through. Nothing is written down — prompts and code are never stored, on the relay or in its database.

What the relay cannot do is act on your editor. It is policy-free by design: the gate deciding which messages may touch your machine lives in the extension, on your machine. Even a compromised relay cannot make your host open a file, run a picker, or change your settings.

A Cloud machine is the exception worth stating plainly: there the host runs on hardware we operate, so the separation above is a policy we keep rather than a wall you own. Keep anything that needs that wall on your own computer.

Apps

Is there an iOS or Android app?

Not yet. Install this site instead — it is built to work as one. On Android, Chrome or Edge, open your dashboard, sign in and use the Install app button in the header; on an iPhone or iPad, tap Share, then Add to Home Screen.

You get an icon on your home screen, a full-screen window with no browser chrome, and a session that stays signed in. It also updates itself, so a fix reaches your phone the moment we ship it, with no store review in between.

Plans

Do I have to pay to use the extension or the desktop app?

No. Both hosts are free and their messages are never limited — the AFK Pilot extension in VS Code, Cursor or another editor it supports, and Grok Build Desktop (Community) on Windows, macOS and Linux. Stay at your keyboard and there is nothing to pay and nothing to count.

What AFK Pilot's Free plan meters is remote messages: the ones you send from your phone or another browser to drive that same agent while you're away from the desk. That's 100 a week on 1 linked device — Remote Max removes the limit.

What happens when I hit the free limit?

Sending from the browser pauses until your weekly window resets — Tuesdays at 17:00 Europe/Warsaw — and the usage meter shows the countdown once you pass 80%. Nothing is lost — the agent, your sessions and VS Code carry on exactly as normal at the desk. The one-device limit works the same way: link a second machine and you will be asked to upgrade rather than cut off.

How does payment work, and can I get an invoice?

Checkout runs through Stripe. We never see or store your card details, and starting on Free never asks for a card at all.

Every payment gets a receipt by email. If you need a proper VAT invoice, write to [email protected] and we will issue one.

How do I cancel?

From your account page, any time. Access runs to the end of the period you have paid for and then drops back to Free — your linked devices and your sessions stay where they are. A Cloud machine stops being reachable when the plan that included it ends, and may be reclaimed after that, so move anything you want to keep off it first.
