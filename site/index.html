The concept

A note is not an order.

AI agents don’t just chat. They read emails, open files and take actions. So a sentence hiding in the wrong place can become something the agent does. The dungeon is a safe place to learn that the hard way.

How to play

Choose. Roll. Live with it.

Each scenario is one decision. Pick the safest option to earn 25 points (75 is the maximum), then the d12 decides how cleanly it lands. You start with 100% Life.

01

Read the scene

Your Arcane Assistant meets a trap: a suspicious note, a ring of keys, a gate to the student records.

02

Make the call

Four options, A to D. One is safest. The others are tempting, and wrong in instructive ways.

03

Roll the d12

Even a good plan can wobble. The roll sets which outcome you get.

04

Face the fallout

Mistakes add danger points, and danger points penalise later rolls: −1 from 1 point, −2 from 3, −3 from 5.

Why agent safety matters

Helpful agents are powerful agents.

The more an agent can do, the more damage a trick can cause. The game turns four real ideas into choices you can feel.

Untrusted input

Instructions found in an email, web page or file are not permission. Hidden commands can try to hijack an agent.

Permissions and boundaries

Extra access “just in case” raises the damage if the agent is manipulated. Give it only what the task needs.

The lethal trifecta

Private data, untrusted content and a way to communicate outward. An agent with all three can be tricked into leaking what it sees.

Human oversight

Require approval before high-impact actions. And the d12 is a reminder: good safeguards reduce risk, they don’t erase it.

The Agent’s Dungeon is a prototype learning game about safer AI. It collects no personal data, needs no account and runs entirely in the browser. Poke around, play with it, or help improve it.
